# Security policy

## Report a vulnerability

Do not open a public issue. Use
[Report a vulnerability](https://github.com/nicolabovolato/paron/security/advisories/new) in the
Security tab of this repository. Only you and the maintainer can see the report.

## Supported versions

Only the latest release gets security fixes.

## Security model

What Paron encrypts, and what an attacker gets from a copy of the database or from the server:
[paron.bovolato.dev/docs/security](https://paron.bovolato.dev/docs/security/).
