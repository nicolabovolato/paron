## One program, one directory

The server, the web UI and the tunnel broker are one program, and the tunnel on a machine is the same
program. It needs no database server and no second service. At the first start, Paron sets up its
certificate and the first administrator.

## Scope

Paron connects to machines over SSH. Users open terminals in the web UI. Paron does not record the
sessions.

## Install

<Tabs>
  <TabItem label="Linux + macOS">

    Install `paron`, and set up the server:

    ```sh
    curl -fsSL https://paron.bovolato.dev/install.sh | sh
    paron server bootstrap
    ```

    See [Install with the binary](/docs/get-started/install-with-the-binary/).

  </TabItem>
  <TabItem label="Windows">

    In PowerShell as administrator, install `paron`, and set up the server:

    ```powershell
    irm https://paron.bovolato.dev/install.ps1 | iex
    paron server bootstrap
    ```

    See [Install with the binary](/docs/get-started/install-with-the-binary/).

  </TabItem>
  <TabItem label="Docker">

    Save this file as `docker-compose.server.yml`, and set the three marked values. The URLs are the ones that your browser and your machines use
    for Paron, and the first one is in links. If no URL has a public domain, remove the two lines for Let's Encrypt.

    <Code
      code={compose}
      lang="yaml"
      title="docker-compose.server.yml"
      mark={[/PARON_(?:PUBLIC_URL|LETSENCRYPT|ACME_CONTACT): .*/g]}
    />

    Start it:

    ```sh
    docker compose -f docker-compose.server.yml up -d
    ```

    See [Install with Docker](/docs/get-started/install-with-docker/).

  </TabItem>
</Tabs>
